# Как найти IP адрес компьютера для подключения iPhone

## Проблема
Реальный iPhone не может подключиться к `localhost` компьютера, так как они находятся в разных сетях.

## Решение
Нужно использовать IP адрес вашего компьютера в локальной Wi-Fi сети.

## Как найти IP адрес

### Windows

1. Откройте командную строку (Win + R, введите `cmd`)
2. Выполните команду:
   ```cmd
   ipconfig
   ```
3. Найдите раздел "Адаптер беспроводной локальной сети Wi-Fi" или "Ethernet adapter"
4. Найдите строку "IPv4-адрес" - это ваш IP (например: `192.168.1.100`)

### Mac

1. Откройте Терминал
2. Выполните команду:
   ```bash
   ifconfig | grep "inet " | grep -v 127.0.0.1
   ```
   Или:
   ```bash
   ipconfig getifaddr en0
   ```
3. Вы увидите IP адрес (например: `192.168.1.100`)

### Linux

1. Откройте терминал
2. Выполните команду:
   ```bash
   ip addr show
   ```
   Или:
   ```bash
   hostname -I
   ```
3. Найдите IP адрес в локальной сети (обычно начинается с `192.168.` или `10.`)

## Настройка в приложении

1. Откройте файл `services/api.ts`
2. Найдите строку:
   ```typescript
   const DEVICE_IP = 'YOUR_COMPUTER_IP';
   ```
3. Замените `YOUR_COMPUTER_IP` на ваш IP адрес:
   ```typescript
   const DEVICE_IP = '192.168.1.100'; // Ваш IP адрес
   ```

## Важные требования

### 1. Одна Wi-Fi сеть
- ✅ iPhone и компьютер должны быть подключены к **одной и той же Wi-Fi сети**
- ❌ Не работает, если iPhone на мобильном интернете, а компьютер на Wi-Fi

### 2. Firewall
Убедитесь, что порт 8080 открыт в firewall:

**Windows:**
1. Откройте "Брандмауэр Защитника Windows"
2. Нажмите "Дополнительные параметры"
3. Создайте правило для входящих подключений на порт 8080

**Mac:**
1. Системные настройки → Безопасность → Брандмауэр
2. Нажмите "Параметры" и разрешите входящие подключения для Java/Spring Boot

### 3. Сервер должен быть запущен
Убедитесь, что Spring Boot сервер запущен и слушает на `0.0.0.0:8080` (не только localhost).

## Проверка подключения

1. На iPhone откройте Safari
2. Введите в адресной строке: `http://ВАШ_IP:8080/api/auth/health`
3. Если видите ответ `{"success":true,"data":"OK"}`, значит подключение работает!

## Альтернативные решения

### Вариант 1: Использовать ngrok (для тестирования)
```bash
# Установите ngrok
# Запустите туннель
ngrok http 8080

# Используйте полученный URL (например: https://abc123.ngrok.io)
```

### Вариант 2: Использовать Expo Tunnel
```bash
# При запуске Expo используйте флаг --tunnel
npx expo start --tunnel
```

### Вариант 3: Развернуть сервер на облачном хостинге
Используйте реальный сервер (AWS, Heroku, DigitalOcean и т.д.)

## Пример настройки

После настройки ваш `services/api.ts` должен выглядеть так:

```typescript
// Замените на ваш IP адрес
const DEVICE_IP = '192.168.1.100'; // Например, ваш IP
```

И при запуске на реальном iPhone будет использоваться:
```
http://192.168.1.100:8080/api
```
