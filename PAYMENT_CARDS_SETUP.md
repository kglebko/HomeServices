# Настройка функционала платежных карт

## Описание

Реализован функционал добавления, просмотра и управления платежными картами с хэшированием чувствительных данных.

## Безопасность

- **Номер карты**: Хэшируется с помощью SHA-256, сохраняются только последние 4 цифры
- **CVV**: Хэшируется с помощью SHA-256
- **Другие данные**: Сохраняются в открытом виде (имя держателя, срок действия)

### 2. Структура таблицы

- `id` - Уникальный идентификатор
- `user_id` - Связь с пользователем
- `card_number_hash` - Хэш номера карты (SHA-256)
- `card_number_last4` - Последние 4 цифры для отображения
- `expiry_month` - Месяц истечения (MM)
- `expiry_year` - Год истечения (YY)
- `cardholder_name` - Имя держателя карты
- `cvv_hash` - Хэш CVV кода
- `card_type` - Тип карты (Visa, MasterCard, etc.)
- `is_default` - Карта по умолчанию
- `is_active` - Активна ли карта
- `created_at`, `updated_at` - Временные метки

### 1. Файлы для добавления

Скопируйте файлы из папки `backend-examples/` в соответствующие пакеты вашего проекта:

### 2. Зависимости

Убедитесь, что в `pom.xml` или `build.gradle` есть:

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-validation</artifactId>
</dependency>
```

### 3. Настройка безопасности

Убедитесь, что контроллер защищен JWT аутентификацией. Добавьте в `SecurityConfig`:

```java
.requestMatchers("/api/cards/**").authenticated()
```

### 4. API Endpoints

- `GET /api/cards` - Получить все карты пользователя
- `POST /api/cards` - Добавить новую карту
- `DELETE /api/cards/{cardId}` - Удалить карту
- `PUT /api/cards/{cardId}/set-default` - Установить карту по умолчанию

## Использование

### Добавление карты

1. Перейдите в Профиль → Добавить карту
2. Нажмите "Добавить карту"
3. Заполните форму:
   - Номер карты (13-19 цифр)
   - Срок действия (MM/YY)
   - CVV (3 цифры)
   - Имя держателя карты
4. Нажмите "Добавить карту"

### Удаление карты

1. Откройте список карт
2. Долгое нажатие на карту
3. Подтвердите удаление

## Безопасность данных

⚠️ **Важно**: 
- Номер карты и CVV хэшируются на бэкенде
- На фронтенде данные передаются по HTTPS
- Рекомендуется использовать дополнительное шифрование для передачи данных
