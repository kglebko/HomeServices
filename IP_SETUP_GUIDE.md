# Настройка подключения iPhone к серверу разработки

## Проблема
Реальный iPhone не может подключиться к `localhost:8080`, так как `localhost` на iPhone указывает на сам iPhone, а не на ваш компьютер.

## Решение
Используйте IP адрес вашего компьютера в локальной Wi-Fi сети.

## Быстрая настройка

### Шаг 1: Узнайте IP адрес вашего компьютера

**Windows:**
```cmd
ipconfig
```
Найдите "IPv4-адрес" в разделе "Адаптер беспроводной локальной сети Wi-Fi" (например: `192.168.1.100`)

**Mac:**
```bash
ifconfig | grep "inet " | grep -v 127.0.0.1
```
Или:
```bash
ipconfig getifaddr en0
```

**Linux:**
```bash
hostname -I
```
Или:
```bash
ip addr show
```

### Шаг 2: Установите IP в коде

Откройте `services/api.ts` и найдите:
```typescript
const DEVICE_IP = 'YOUR_COMPUTER_IP';
```

Замените на ваш IP:
```typescript
const DEVICE_IP = '192.168.1.100'; // Ваш IP адрес
```

### Шаг 3: Убедитесь, что устройства в одной сети

- ✅ iPhone подключен к Wi-Fi
- ✅ Компьютер подключен к той же Wi-Fi сети
- ❌ Не работает, если iPhone на мобильном интернете

### Шаг 4: Проверьте Firewall

**Windows:**
1. Откройте "Брандмауэр Защитника Windows"
2. "Дополнительные параметры" → "Правила для входящих подключений"
3. Создайте новое правило для порта 8080 (TCP)

**Mac:**
1. Системные настройки → Безопасность → Брандмауэр
2. "Параметры" → Разрешите входящие подключения для Java

### Шаг 5: Проверьте подключение

На iPhone откройте Safari и введите:
```
http://ВАШ_IP:8080/api/auth/health
```

Если видите `{"success":true,"data":"OK"}`, значит все работает! ✅

## Альтернативный способ: переменная окружения

Можно использовать переменную окружения вместо изменения кода:

1. Создайте файл `.env` в корне проекта:
```
EXPO_PUBLIC_API_IP=192.168.1.100
```

2. Перезапустите Expo:
```bash
npx expo start --clear
```

## Проверка в приложении

После настройки в консоли приложения должно появиться:
```
📱 Используется IP адрес для реального устройства: http://192.168.1.100:8080/api
```

## Частые проблемы

### Проблема: "Network request failed"
**Решение:**
- Проверьте, что IP адрес правильный
- Убедитесь, что iPhone и компьютер в одной Wi-Fi сети
- Проверьте firewall на компьютере

### Проблема: "Connection refused"
**Решение:**
- Убедитесь, что Spring Boot сервер запущен
- Проверьте, что сервер слушает на `0.0.0.0:8080`, а не только `localhost:8080`

### Проблема: IP адрес меняется
**Решение:**
- Настройте статический IP адрес в настройках роутера
- Или используйте переменную окружения и обновляйте её при необходимости
